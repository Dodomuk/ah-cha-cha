# UI/UX 설계

**버전:** 2.0
**최종 수정:** 2026-06-04

---

## 1. 디자인 철학

- **실시간성**: WebSocket을 통한 즉각적인 뉴스 업데이트
- **명확성**: 위협 수준을 색상과 숫자로 직관적 표현
- **효율성**: 한눈에 글로벌 상황 파악 가능
- **접근성**: 모바일/데스크톱 모두 지원

---

### 2-1. 전체 구조

```
┌────────────────────────────────────────────────────────┐
│                    Ah-Cha-Cha                           │
│         Real-time Breaking News Dashboard               │
└────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────┐
│                                                          │

│          [D3.js 세계 지도 + 속보 마커]                   │
│          - 위협 수준별 색상 (1:초록, 4:빨강)             │
│          - 클릭 가능한 마커                               │
│          - 실시간 애니메이션                              │
│                                                          │

└────────────────────────────────────────────────────────┘

┌──────────────────────┐  ┌───────────────────────────────┐
│  [팝업 카드]          │  │  [속보 목록 (우상단)]           │

│  - 요약              │  │  │ 🌀 New Event (스피너)     │  │

│  - 위협도 배지       │  │  │ [기사 1] - Today          │  │
```

### 2-2. 색상 스키마

| 위협 수준 | 색상 | 사용처 | 의미 |
|----------|------|--------|------|
| 1 | 초록 `#00e676` | 마커, 배지 | 낮음 |
| 2 | 노랑 `#ffc107` | 마커, 배지 | 중간 |
| 3 | 주황 `#ff9100` | 마커, 배지 | 높음 |

배경: 검은색 (`#000000`)
텍스트: 흰색 (`#ffffff`)
강조: 사이버초록 (`#00e676`)

## 3. 팝업 카드 (기사 상세)

### 3-1. 구조

```
┌─────────────────────────────────────┐
│ 🌀 New Event                  [⏸/▶] │  <- 헤더 (sticky, z: 999)
├─────────────────────────────────────┤
│                                     │
│ [emoji] Breaking News Title         │
│         (단어 2-3개씩 reveal)        │
│                                     │
│ Summary text revealed word by...    │
│ (단어 2-3개씩, 천천히 appear)       │
│                                     │
│ [태그] US  [태그] RU                │
│                                     │
│ #Keyword1  #Keyword2  #Keyword3     │
│                                     │
│ Auto-rotating (5/50)                │
│ Collected: 2h ago                   │
└─────────────────────────────────────┘
```

### 3-2. 애니메이션

| 요소 | 타입 | 지속시간 | 설명 |
|------|------|---------|------|
| 슬라이드 | slideDown | 0.5s | 카드 등장 |
| 단어 reveal | fadeInWord | 250ms (타이틀) | 단어별 나타남 |
| 단어 reveal | fadeInWord | 150ms (요약) | 더 빠른 속도 |
| 배지 스핀 | spin | 2s | 위협도 배지 회전 |
| 펄스 | pulse | 2s | 글로우 효과 |

### 3-3. 스타일

```css
/* 글래스모피즘 */
backdrop-filter: blur(10px);
background: rgba(10, 25, 47, 0.95);
border: 1px solid rgba(0, 230, 118, 0.15);
border-radius: 12px;

/* 섀도우 */
box-shadow: 0 8px 32px rgba(0, 230, 118, 0.02);
```

## 4. 속보 목록 (우상단)

### 4-1. 구조

```
┌──────────────────────┐
│ Latest News     [⏸/▶]│  <- sticky header (z: 999)
├──────────────────────┤
│ [Today]               │
│ ┌────────────────┐   │
│ │ Article 1      │   │
│ │ [기사 제목..]   │   │
│ │ US, RU         │   │
│ └────────────────┘   │
│ [Yesterday]           │
│ ┌────────────────┐   │
│ │ Article 2      │   │
│ └────────────────┘   │
│ [2 days ago]         │
│ ┌────────────────┐   │
│ │ Article 3      │   │
│ └────────────────┘   │
│                      │
│ (스크롤 가능)       │
└──────────────────────┘
```

### 4-2. 상호작용

| 액션 | 동작 |
|------|------|
| 클릭 | 팝업 카드에 기사 표시 |
| 20초 후 | 자동으로 슬라이드쇼 재개 |
| 새 속보 | 목록 최상단에 추가, 스피너 표시 3초 |
| 호버 | 배경색 변화 |
| 선택 상태 | 초록 배경 + 테두리 |

## 5. 세계 지도

### 5-1. 렌더링

- **라이브러리**: D3.js (geoMercator 투영)
- **포맷**: TopoJSON (countries-110m.json)
- **렌더링**: SVG + HTML Canvas 혼합

### 5-2. 마커

```
위험도별 마커 반경:
- 1-2: 6px
- 3: 8px  
- 4: 10px

색상: 위협도 색상 (위 참고)
```

### 5-3. 인터랙션

- **호버**: 마커 확대, 국가명 표시
- **클릭**: 팝업 카드 표시

---

## 6. 실시간 업데이트 UI

### 6-1. 새 속보 도착

```
[Latest News] → [🌀 New Event]  (3초 동안 스피너)
  ↓
기사 목록 최상단에 추가
  ↓
팝업 카드 자동 전환
```

### 6-2. 자동 슬라이드쇼

- **간격**: 12초
- **중지**: 기사 클릭 시
- **재개**: 20초 후 자동
- **상태**: ⏸/▶ 버튼으로 수동 제어

## 7. 반응형 디자인

### 7-1. 모바일 (< 768px)

- 세계 지도: 풀스크린
- 팝업 카드: 풀너비 바텀시트
- 속보 목록: 사이드 드로어 (슬라이드 아웃)
- 터치 이벤트 지원

### 7-2. 태블릿 (768px ~ 1024px)

- 세계 지도: 80% 너비
- 속보 목록: 사이드 패널 20%
- 팝업 카드: 왼쪽 하단

### 7-3. 데스크톱 (> 1024px)

- 세계 지도: 65% 너비
- 팝업 카드: 왼쪽 하단 30%
- 속보 목록: 우상단 300px
