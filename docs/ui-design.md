## 1. 디자인 원칙

- **사이버 대시보드 미학**: 검은 배경 위 디지털 와이어프레임 지도. 네온 글로우로 깊이감 표현.
- **지도가 주인공**: 전체 뷰포트를 지도가 채움. 패널은 지도 위에 오버레이.
- **색상은 위협 언어**: 빨강/주황/노랑은 오직 위협 정보에만 사용. 기본 상태는 네온 블루.
- **정보는 계층적으로**: 지도(국가 수준) → 패널(사건 수준) → 카드(세부 내용).

---

## 2. 지도 비주얼 레퍼런스

목표 스타일: **디지털 폴리곤 메시 세계 지도**

```
특징:
- 검은색(#000000 ~ #03071E) 배경
- 국가 경계가 다각형 메시(폴리곤 와이어프레임)로 표현
- 경계선과 폴리곤 면에 네온 블루 글로우 (기본 상태)
- 보안 사건 발생 시 해당 국가가 빨강/주황/노랑으로 점등
- 글로우 효과: Canvas shadowBlur로 구현 (Photoshop 외광 효과)
```

렌더링 기술: **D3.js (GeoJSON 프로젝션) + HTML Canvas 2D**

## 5. 컴포넌트 상세

### 5.1 헤더

- 좌측: `아차차` 로고 (네온 블루 계열) + 영문 서브타이틀
- 중앙: 마지막 갱신 시각 표시 (예: "마지막 업데이트: 2026-05-21 08:00")
- 우측: 광고 배너 슬롯 (Google AdSense 728x90 or 반응형)

### 5.2 지도 Canvas 렌더링 (WorldMap)

```javascript
// 핵심 렌더링 로직 개요
ctx.shadowBlur = 15
ctx.shadowColor = threatColor  // 위협 레벨별 글로우 색상
ctx.fillStyle = threatFill
ctx.fill(countryPath)          // D3 path generator로 생성한 path

// 기본 상태 (None)
ctx.shadowColor = '#0077B6'
ctx.shadowBlur = 8
ctx.strokeStyle = '#00B4D8'
ctx.stroke(countryPath)
```

- 호버: 해당 국가 `shadowBlur` 증폭 (8 → 20), 커서 `pointer`
- 클릭: Zustand에 선택 국가 코드 저장 → 패널 오픈
- 툴팁: Canvas 위 absolute HTML 요소로 국가명 + 위협 레벨 표시

### 5.3 국가 상세 패널 (CountryPanel)

- 위치: 화면 우측 고정, 슬라이드 인/아웃 애니메이션 (CSS transform)
- 너비: 380px (데스크탑)
- 배경: `rgba(13, 27, 42, 0.92)` + backdrop-filter blur
- 테두리: 좌측에만 `2px solid #00B4D8` + 미약한 글로우
- 구성:
  - 국가명 (한국어) + 국기 이모지 + 위협 레벨 배지
  - 위협 레벨 설명 텍스트 (예: "High — 심각한 보안 위협")
  - 뉴스 카드 스크롤 목록
  - 광고 슬롯 (300x250)
  - 닫기 버튼

## 6. 반응형 고려 (MVP는 데스크탑 우선)

| 브레이크포인트 | 레이아웃 변화 |
|---------------|--------------|
| `≥ 1024px` | 기본 레이아웃 (지도 + 우측 패널) |
| `< 1024px` | 패널이 하단에서 슬라이드 업 (Phase 2) |
| `< 768px` | 모바일 앱으로 분리 (Phase 2) |

MVP는 데스크탑(1024px 이상)을 주 대상으로 개발.
