## 1. 디자인 원칙

- **사이버 대시보드 미학**: 검은 배경 위 디지털 와이어프레임 지도. 네온 글로우로 깊이감 표현.
- **지도가 주인공**: 전체 뷰포트를 지도가 채움. 패널은 지도 위에 오버레이.
- **색상은 위협 언어**: 빨강/주황/노랑은 오직 위협 정보에만 사용. 기본 상태는 네온 블루.
- **아이콘 우선**: 버튼은 텍스트 없이 아이콘만 사용. 툴팁으로 의미 전달.
- **글로우모피즘**: 팝업·툴팁·필터는 backdrop-filter blur + rgba 반투명 배경.

## 4. 컴포넌트 상세

### 4.1 헤더

- 좌측: `아차차` 로고 (흰색) + `GLOBAL CYBER THREAT MONITOR` 부제 (네온 블루, 레터 스페이싱)
- 중앙: 마지막 갱신 시각 표시 (`snapshot_at` 기준)
- 배경: 완전 투명 → 지도 위에 플로팅

### 4.2 지도 Canvas (WorldMap)

**렌더링:**
- `D3.js geoNaturalEarth1` 프로젝션
- `HTML Canvas 2D` + `devicePixelRatio` HiDPI 지원
- `Path2D` 캐시로 반복 렌더링 최적화
- 마우스 쓰로틀: 25ms 시간 기반 + 3px 거리 필터

**히트 테스트:**
- `ctx.resetTransform()` 후 `ctx.isPointInPath(path2D, x, y)` 사용
- DPR 스케일 관계없이 CSS 픽셀 기준으로 정확한 좌표 판정
- `geoContains` 방식 대비 안티메리디안(러시아, 캐나다) 오감지 해결

**날짜 전환:**
- 날짜 필터 변경 시 `isTransitioning = isFetching && !!data` 동안 "지도 갱신 중..." 오버레이 표시
- `keepPreviousData`: 로딩 중에도 이전 지도 색상 유지 (빈 지도 플래시 없음)
- `threatDataRef` 패턴으로 `drawMap` 함수를 stable 유지 → GeoJSON 재요청 없음

### 4.3 마우스 툴팁 (MapTooltip)

- **글로우모피즘**: `rgba(8,8,14,0.88)` 배경 + `backdrop-filter: blur(16px)`
- 표시 내용: **국가명만** (위협 레벨 표시 없음)
- `whiteSpace: nowrap` — 전체 국가명 잘림 없이 표시
- 마우스 커서 우측 8px 오프셋 배치
- 국가 위에 있을 때만 표시, 벗어나면 즉시 사라짐

### 4.4 날짜 범위 필터 (DateRangeFilter)

- 위치: 좌하단 fixed
- 글로우모피즘 컨테이너
- 버튼: `오늘` (24h) / `3일` (72h) / `7일` (168h, 기본값)
- 선택 시 Zustand `hours` 업데이트 → 지도 + 국가 패널 모두 연동

### 4.5 국가 상세 패널 (CountryPanel)

- 위치: 화면 우측 고정 오버레이, 슬라이드 인/아웃 (`translateX`)
- 너비: 520px
- 배경: `rgba(8,8,14,0.92)` + `backdrop-filter: blur(16px)`
- 테두리: 좌측 `1px solid rgba(0,180,216,0.18)` + 박스 쉐도우
- 구성:
  - 국기 이모지 + 국가명 (한국어)
  - 보안 이슈 N건 (article_count)
  - 뉴스 카드 스크롤 목록
  - 닫기 버튼 (우상단 ×)
- 날짜 필터 `hours`와 연동 (`useCountryNews(code, hours)`)

### 4.6 뉴스 카드 (NewsCard)

```
┌────────────────────────────────────────────────┐
│ ● 한국 금융기관 대상 사이버 공격 탐지           │  ← 위협 레벨 컬러 글로우 닷 + 제목
│                                                │
│ 무슨 일: 화요일, 주요 시중은행 5곳의 전산망에  │
│         DDoS 공격이 발생...                    │
│                                                │
│ 영향: 약 3시간 서비스 장애, 추정 피해액        │
│      수십억 원 규모...                          │
│                                                │
│ ─────────────────────────────────────────────  │
│ boannews.com  [원문 보기 →]  4h 전             │
└────────────────────────────────────────────────┘
```

- 위협 레벨 배지: 텍스트 없이 **컬러 글로우 닷**만 표시 (Critical=빨강, High=주황, Medium=노랑, Low=초록)
- 카드 좌측 border: 위협 레벨 색상 (`2px solid`)
- 이슈 간 간격: `marginBottom: 28px`
- 원문 보기 링크와 다음 이슈 제목 사이 간격: `marginTop: 20px, paddingTop: 12px`
- 텍스트 크기: `13px`, 색상: `#c8dfe8`

### 4.7 일일 리포트 패널 (DailyReportPanel)

- **플로팅 버튼**: 우하단 fixed, 원형 (40×40), 문서 아이콘 SVG
- **사이드 패널**: 우측에서 슬라이드 인, 너비 420px
- 내용: 오늘(최근 24h) 수집된 기사 목록 (위협 높은 순)
- **다운로드 버튼**: 아이콘만, 클릭 시 `.txt` 파일 다운로드
- 닫기 버튼: ×
