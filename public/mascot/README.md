# 차차 마스코트 애셋

사용자가 직접 제공 예정. 아래 상태별 애셋이 필요하다 (prd.md 6.2 참조).

| 파일 | 쓰임 |
| --- | --- |
| `chacha-idle.*` | 홈 — 기본 상태 |
| `chacha-diving.*` | 검사 중 — 링크 안으로 뛰어드는 모습 |
| `chacha-relieved.*` | 결과: 이상 없음 |
| `chacha-puzzled.*` | 결과: 주의 / 정보 부족 |

위험(`danger`) 판정 화면에는 마스코트를 쓰지 않는다. 경고가 화면을 차지해야 하고,
귀여움이 경고를 부드럽게 만들면 안 되기 때문 (CLAUDE.md 규칙 9).
